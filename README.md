<h2>Quick Start</h2>
<lu>
  <li>Download AutoHotkey v2.0</li>
  <li>Download Accept.ahk</li>
  <li>Launch CS2</li>
  <li>Run Accept.ahk with administrator rights and press F3 if the game is in full screen mode, and in other cases press F2.</li>
  <li>Start match selection</li>
  <li>Once you are launched into the match, you can press the F2 button to close the ahk script</li>
  <li>Have a good game</li>
</lu>
<h2>Why do you need administrator rights?</h2>
Administrator rights are needed so that the script can control the machine while the CS2 game is open.<br><br>
